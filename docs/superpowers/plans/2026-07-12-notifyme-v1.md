# NotifyMe v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zero-configuration Claude Code plugin that notices deadlines in any conversation, creates Apple Reminders that fire on the user's iPhone, and can resume the work context weeks later.

**Architecture:** Skills (prompts) own all conversation logic and call one stable CLI (`scripts/notifyme.sh`), which validates input, maintains a local decision journal (`journal.jsonl`), and delegates delivery to a swappable adapter (`scripts/adapters/apple-reminders.sh`) where **all** AppleScript lives. A SessionStart hook injects one sentence so every project is deadline-aware.

**Tech Stack:** bash + `osascript` (AppleScript for Reminders, JXA for JSON). **No other dependencies** — no jq, python, or node anywhere in runtime code.

## Global Constraints

- macOS-only runtime; every runtime dependency must ship with macOS (bash, osascript).
- No telemetry, no network calls — the single exception is doctor's on-demand update check (`api.github.com`).
- Error messages shown to users: ≤ 2 sentences, name the fix, never expose AppleScript error text (spec §10 has exact strings).
- Reminder title/body are written in the user's conversation language; SKILL.md files themselves are English.
- The datetime contract between skills and `notifyme.sh` is **local naive** `YYYY-MM-DDTHH:MM` (adapter consumes components; no timezone math anywhere).
- List name default: `Claude Projects`. State dir default: `~/.claude/notifyme/`. Env overrides for tests: `NOTIFYME_LIST`, `NOTIFYME_STATE_DIR`, `NOTIFYME_ADAPTER`.
- Journal statuses: `accepted | declined | deferred | cancelled | done` (spec §7); append-only, last line per `id` wins.
- Never claim success without adapter verification (read-back). Never delete/complete anything in Reminders without explicit user consent in conversation.
- Commit after every task; messages end with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```bash
#!/bin/bash
# NotifyMe delivery adapter: Apple Reminders. ALL AppleScript lives here.
# Contract (spec §12): add | list | status | complete | delete | health
set -uo pipefail
LIST="${NOTIFYME_LIST:-Claude Projects}"
OSA=/usr/bin/osascript

# Exit codes: 10 permission denied, 11 verify failed, 12 other failure
run_osa() { # stdin: applescript; args: argv for the script
  local out
  out=$("$OSA" - "$@" 2>&1 </dev/stdin)
  local rc=$?
  if [ $rc -ne 0 ]; then
    case "$out" in
      *-1743*|*"Not authorized"*) echo "permission" >&2; exit 10 ;;
      *-600*) echo "reminders-app-unavailable" >&2; exit 12 ;;
      *) echo "$out" >&2; exit 12 ;;
    esac
  fi
  printf '%s' "$out"
}

resolve_account() { # prints "<flag>\t<account>": flag=icloud|local
  run_osa <<'EOF'
on run argv
  tell application "Reminders"
    set accNames to name of every account
    if accNames contains "iCloud" then return "icloud" & tab & "iCloud"
    return "local" & tab & (item 1 of accNames)
  end tell
end run
EOF
}

ensure_list() { # $1 account
  run_osa "$1" "$LIST" <<'EOF' >/dev/null
on run argv
  tell application "Reminders"
    tell account (item 1 of argv)
      if not (exists list (item 2 of argv)) then
        make new list with properties {name:(item 2 of argv)}
      end if
    end tell
  end tell
end run
EOF
}

cmd="${1:-}"; shift || true
case "$cmd" in
  health)
    acct_info=$(resolve_account)
    flag="${acct_info%%$'\t'*}"; acct="${acct_info#*$'\t'}"
    ensure_list "$acct"
    if [ "$flag" = "icloud" ]; then echo "ok $acct/$LIST"; else echo "ok-local $acct/$LIST"; fi
    ;;
  *)
    echo "unknown command: $cmd" >&2; exit 2 ;;
esac
```

```bash
#!/bin/bash
# NotifyMe CLI façade. Skills call this and never the adapter directly.
# Commands: add | log | list | get | cancel | complete | due-deferrals | prune | health | selftest
set -uo pipefail
SELF_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
STATE_DIR="${NOTIFYME_STATE_DIR:-$HOME/.claude/notifyme}"
ADAPTER="${NOTIFYME_ADAPTER:-$SELF_DIR/adapters/apple-reminders.sh}"
JOURNAL="$STATE_DIR/journal.jsonl"
OSA=/usr/bin/osascript

mkdir -p "$STATE_DIR"
[ -f "$STATE_DIR/config.json" ] || printf '{ "list_name": "Claude Projects", "default_hour": 9 }\n' > "$STATE_DIR/config.json"
touch "$JOURNAL"

die2() { echo "$1" >&2; exit 2; }

validate_due() { # $1: YYYY-MM-DDTHH:MM (local); dies with exit 2, else echoes y m d H M
  [[ "$1" =~ ^([0-9]{4})-([0-9]{2})-([0-9]{2})T([0-9]{2}):([0-9]{2})$ ]] \
    || die2 "invalid datetime: '$1' (need YYYY-MM-DDTHH:MM, local time)"
  local y=${BASH_REMATCH[1]} m=${BASH_REMATCH[2]} d=${BASH_REMATCH[3]} H=${BASH_REMATCH[4]} M=${BASH_REMATCH[5]}
  local epoch
  epoch=$(date -j -f "%Y-%m-%dT%H:%M" "$1" +%s 2>/dev/null) || die2 "impossible date: '$1'"
  [ "$epoch" -gt "$(date +%s)" ] || die2 "date is in the past: '$1'"
  echo "$y $m $d $H $M"
}

cmd="${1:-}"; shift || true
case "$cmd" in
  add)
    due="${1:-}"; title="${2:-}"
    [ -n "$title" ] || die2 "empty title"
    read -r y m d H M <<< "$(validate_due "$due")"
    echo "TODO Task 6" >&2; exit 1
    ;;
  health)
    "$ADAPTER" health
    ;;
  *) die2 "unknown command: $cmd" ;;
esac
```

Add a JXA bridge near the top of `notifyme.sh` (after `die2`):
```bash
jxa_journal() { # $1: mode (append|list|get|due|prune), then mode args; env passes fields
  "$OSA" -l JavaScript - "$JOURNAL" "$@" <<'EOF'
ObjC.import('Foundation');
function readLines(p) {
  const s = $.NSString.stringWithContentsOfFileEncodingError(p, $.NSUTF8StringEncoding, null);
  if (!s || s.isNil && s.isNil()) return [];
  return ObjC.unwrap(s).split('\n').filter(l => l.trim()).map(l => JSON.parse(l));
}
function lastState(entries) {
  const m = {};
  entries.forEach(e => { m[e.id] = e; });
  return Object.values(m);
}
function env(k) { const v = $.NSProcessInfo.processInfo.environment.objectForKey(k); return v.isNil() ? "" : ObjC.unwrap(v); }
function run(argv) {
  const path = argv[0], mode = argv[1];
  if (mode === 'append') {
    const e = {
      id: env('NOTIFYME_ID') || 'nm_' + Date.now() + '_' + Math.floor(Math.random()*1e6),
      status: argv[2], title: argv[3], due: argv[4] === '-' ? '' : argv[4],
      project: env('NOTIFYME_PROJECT'), project_path: env('NOTIFYME_PROJECT_PATH'),
      context: env('NOTIFYME_CONTEXT'), resume_prompt: env('NOTIFYME_RESUME_PROMPT'),
      reminder_id: env('NOTIFYME_REMINDER_ID'), reoffer_at: env('NOTIFYME_REOFFER_AT'),
      created_at: new Date().toISOString()
    };
    Object.keys(e).forEach(k => { if (e[k] === '') delete e[k]; });
    const line = JSON.stringify(e) + '\n';
    const fh = $.NSFileHandle.fileHandleForWritingAtPath(path);
    fh.seekToEndOfFile; fh.seekToEndOfFile();
    fh.writeData($.NSString.alloc.initWithUTF8String(line).dataUsingEncoding($.NSUTF8StringEncoding));
    fh.closeFile();
    return e.id;
  }
  const states = lastState(readLines(path));
  if (mode === 'list') {
    const status = argv[2] || 'all', project = argv[3] || '';
    return states
      .filter(e => status === 'all' || e.status === status)
      .filter(e => !project || e.project === project)
      .map(e => JSON.stringify(e)).join('\n');
  }
  if (mode === 'get') {
    const hit = states.find(e => e.id === argv[2]);
    if (!hit) { return '__NOTFOUND__'; }
    return JSON.stringify(hit);
  }
  if (mode === 'due') {
    const now = new Date();
    // reoffer_at is local naive YYYY-MM-DDTHH:MM — compare as local
    return states.filter(e => e.status === 'deferred' && e.reoffer_at &&
      new Date(e.reoffer_at.replace('T', ' ') + ':00') <= now)
      .map(e => JSON.stringify(e)).join('\n');
  }
  if (mode === 'prune') {
    const drop = new Set(states.filter(e => e.status === argv[2]).map(e => e.id));
    const kept = readLines(path).filter(e => !drop.has(e.id));
    const body = kept.map(e => JSON.stringify(e)).join('\n') + (kept.length ? '\n' : '');
    $.NSString.alloc.initWithUTF8String(body).writeToFileAtomicallyEncodingError(path, true, $.NSUTF8StringEncoding, null);
```

````markdown
## When to offer (etiquette — non-negotiable)

- Trigger on concrete, future, actionable dates/checkpoints from EITHER side
  of the conversation: the user's words ("здати до 26-го") or your own
  conclusions ("раніше кінця липня перевіряти немає сенсу" → offer a reminder
  for the decision point). Never for incidental dates ("у 2024 цей API
  змінився").
- Offer ONCE per distinct deadline, at a natural pause — never interrupt the
  primary task mid-flow. One short sentence, e.g.:
  «До речі — поставити нагадування на 24 липня перевірити GSC Coverage?
  Прийде на iPhone.»
- Propose the MEANINGFUL date — the decision point, not the mention date.
  "14+ днів від 10.07" → offer 24.07. Exactly one option; the user adjusts.
- Before offering, check for duplicates: run `$NOTIFYME list all` and skip
  the offer if an entry with the same intent and date already exists (any
  status). If it exists as active, you may briefly confirm it's already set.
- Time of day: if the user gave none, use the default hour from
  `~/.claude/notifyme/config.json` (`default_hour`, default 9 → 09:00).
- For periodic needs ("перевіряти раз на кілька днів") do NOT create several
  reminders — one reminder at the earliest meaningful date. If the user wants
  true recurrence, tell them: open the just-created reminder in Apple
  Reminders and add a repeat there (one tap; AppleScript cannot set it).
- **Stale awareness**: if the conversation reveals a tracked reminder became
  irrelevant or already happened («гейт ми вже пройшли», «реліз скасували»),
  offer once to close it: `$NOTIFYME complete <id>` (or `cancel <id>` if it
  never happened). Offer — never close anything without consent.

## Recording the user's answer — every answer, always

- **Yes** → create (below).
- **No** → `NOTIFYME_PROJECT="<project>" $NOTIFYME log declined "<title>" "<YYYY-MM-DDTHH:MM>"`
  Never re-offer this deadline; it stays reversible via notifyme:reminders.
- **"Not now / ask closer to the date"** → agree on a re-offer date, then:

- **body** — the fixed template (their language), plain words a person who

- **resume_prompt** — a SELF-CONTAINED continuation prompt for a future
````
